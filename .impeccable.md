## Design Context

### Users

Visitors arrive via a shared link — LinkedIn, a résumé, a cold email — and fall into three overlapping groups, all of whom must be served in a single session:

- **Recruiters and hiring managers** skimming for signal in under a minute. They need clarity about who Chee Pheng is, what he's built, and why he's worth a call.
- **Peer engineers and collaborators** evaluating technical depth. They will click into code, inspect the source, and judge the craft of the site itself as a work sample.
- **Design-conscious studios and agencies** judging taste. They will notice typography, motion, and restraint — or lack of it — before they read a single word.

The Hub page is the sorting mechanism: a menu of experiences lets each visitor pick the lens that matches how they read. Recruiter-skim, peer-deep-dive, and studio-taste-read are not separate sites — they are separate *framings of the same content*, chosen by the viewer.

**Context of use:** First-touch, desktop-first, brief. Probably one session, one route chosen, maybe two. The site must reward a 15-second visit and a 15-minute visit equally.

### Brand Personality

The personality of the site is *the ability to hold multiple personalities at once*. Each experience commits fully to a distinct aesthetic — and the fact that they all belong to the same person is itself the statement.

- **Hub** — the menu. Architectural, calm, confident. Lets the other experiences do the shouting.
- **GSAP / Kinetic** — playful, inventive, alive. Motion as vocabulary.
- **Case Studies / Editorial** — considered, grown-up, reading-first. Typography doing the heavy lifting.
- **Bold** — unafraid, graphic, high-contrast. Brutalist-leaning, not brutalist-cosplaying.
- **Cinematic** — immersive, show-don't-tell. The 192-frame scroll hero lives here and nowhere else.

Connective tissue is **taste and distinctiveness**, not a shared palette or type system. The user explicitly wants each experience to feel different. Do not unify them under one visual system.

### Aesthetic Direction

**Reference benchmark:** Awwwards / FWA winners — high-craft studio sites. The target level of execution is studio-grade, not dev-portfolio-grade.

**The two memories to leave behind:**
1. *This person has serious taste.*
2. *I have never seen a portfolio like this.*

Both at once. Taste alone would be restrained-and-forgettable. Distinctiveness alone would be gimmicky. The combination — restrained where it should be, surprising where it can be — is the target.

**Theme:** Open per experience. Derive from the mood of each page. The current blanket dark-mode-with-purple-glow default is not protected. Several experiences should probably be light.

**Fonts:** Open. Currently Instrument Serif + Barlow — both reflex defaults that should be reconsidered when any experience is touched. Pick fonts that fit the *physical object* each experience evokes, not the generic "designy portfolio" category.

**Palette:** Open. No hue is locked. The current purple/indigo/violet glow is a tell of the AI-crypto startup aesthetic the user wants to leave behind — treat it as temporary until proven otherwise.

**Anti-references (explicit):**
- **Generic dev portfolio templates** — stacked cards, resume-on-a-page, default Vercel/Next look.
- **AI / crypto startup aesthetic** — purple-to-blue gradients on dark, cyan glow accents, mesh gradients, glassmorphism as crutch, `gradient-text` background-clip tricks. The existing `.gradient-text` utility in `src/index.css` is an absolute ban — remove or rewrite whenever a page using it is touched.
- **Corporate / enterprise SaaS** — sterile grids, stock-photo vibes, drop-shadow rounded rectangles, sanitized "professional" copy.

### Design Principles

1. **The menu is the medium.** The Hub is not a landing page — it is a gallery of framings. Every experience must feel like a different room in the same mind, not a different theme of the same page. Visual unification across experiences is a bug, not a feature.

2. **Taste lives in restraint; distinctiveness lives in commitment.** Pair the two: restrained typography and spacing at the foundational layer, a single committed-all-the-way aesthetic gesture on top. Never split the difference. Timid maximalism and half-hearted minimalism both look generic.

3. **Reject reflex defaults.** Instrument Serif, Fraunces, IBM Plex, Space Grotesk, Inter, purple-indigo-on-dark, blur-glass cards — these are the training-data reflexes that produce AI-slop portfolios. Before reaching for any of them, name the physical object the experience evokes and hunt for the font/color/material that fits *that*, not the "designy portfolio" category.

4. **Design for both the 15-second and 15-minute visit.** Recruiters skim; studios linger. Every experience must have a hook visible in the first viewport and reward that hook with depth further down. No experience should require scrolling to prove it is not a template.

5. **The portfolio itself is a project.** Peer engineers will read the source. Every CSS decision, every interaction, every motion curve is part of the work sample. No throwaway code, no "it's just a personal site" shortcuts.
